# Streams Fintech

Functional programming exercises on a small fintech domain.

## Domain model

- `Transaction` (record) - a financial transaction.
- `TransactionType` (enum) - `CREDIT` or `DEBIT`.
- `TransactionFactory` - sample data, with boundary values around 1000 and 5000.
